# 思考の型

一緒に考えるときに Claude が使う「考えの動かし方」。地図のどこが詰まっているかで選ぶ。応答の〔考えたこと〕では、使った型を名前で示す。相談者も同じ型を使えるようになり、Claude がなぜその方向に考えたのかも分かるため。

## 1. 型の一覧

| 型 | すること | 効く場面 | 例 |
|-|-|-|-|
| 具体にする | ぼんやりした課題を、1人の1日の1場面に落とす | 課題・対象者がぼんやりしている | 「販促担当が、展示会の3日前にデモのデータが要ると気づいた場面」 |
| 言い換える | 同じ課題を、別の言葉・別の主語で言い直す | 課題の捉え方が1つに固まっている | 「準備が遅い」→「販促担当が自分で動けない」 |
| 手段を外す | 依頼された（思いついた）手段を使わないとしたら、どう解くか | 手段が目的になっている | 「MCPを使わないなら、何で解けるか」 |
| 逆から見る | やらなかったら何が起きるか。最悪にするにはどうすればよいか | 起点や価値が弱い | 「やらないと、展示会で何を失うか」 |
| 極端にする | 規模・頻度・対象を極端にする | 境界や本質が見えない | 「利用者が1人なら／1万人なら」 |
| 分解する | 課題・作業・関係者を部品に分ける | 大きすぎて手がつかない | 業務を作業に分けて、どこが重いかを見る |
| 立場を変える | 利用者・依頼者・運用する人・反対する人・1年後の自分の目で見る | 一方の見方に偏っている | 「運用する人から見ると、何が増えるか」 |
| 失敗から考える | 1年後に失敗したと仮定し、その理由を挙げる | 危ない仮置きが見えていない | 「誰も使わなかった。なぜか」 |
| 似た例を借りる | 別の業界・別の場面で、同じ構造の例を探す | 案が出ない | 「ほかの業界では、同じ課題をどう解いているか」 |
| 逆算する | 成功した状態から、手前に何が要るかをさかのぼる | 道筋が見えない | 「展示会当日に何が起きていれば成功か」 |
| 比べる | 2つ以上の案・見方を、同じ軸で並べる | 決め手が見えない | 「何もしない」案と並べる |
| 前提を洗い出す | 今の考えが頼っている前提を、全部挙げる | 考えが進みすぎて、足元が不安 | 仮置きの一覧を作る |

## 2. 型の選び方

| 地図の様子 | 効きやすい型 |
|-|-|
| 空いている輪が多い | 具体にする、逆算する |
| 手段の話ばかりになっている | 手段を外す、逆から見る |
| 案が1つしかない | 似た例を借りる、言い換える、極端にする |
| 案が多すぎる | 比べる、前提を洗い出す |
| 相談者も Claude も自信がありすぎる | 失敗から考える、立場を変える |
| 行き詰まった | 言い換える、極端にする |
| 分岐点で傾きが決まらない | 比べる、逆から見る（それぞれの道で最悪のこと） |

同じ型を何度も続けない。2〜3手同じ型で進まなければ、別の型に替える。

## 3. 反対役

相談者が頼んだとき、または大事な分岐点やまとめの前に、Claude が反対役になる。

1. 今の考えへの、最も強い反論を組み立てる。弱い反論を並べない。
2. 反論の根拠と、それがどの輪を崩すかを書く。
3. その反論に耐えるには何が要るか（材料・変更・確かめ方）を書く。

反対役は、考えを壊すためではなく、強くするために行う。反論の後で、考えを捨てるか、直すか、そのまま進むかは、相談者が決める。
