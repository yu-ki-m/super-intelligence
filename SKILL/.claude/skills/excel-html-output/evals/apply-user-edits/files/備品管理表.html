Excel形式の編集とコピー

範囲と編集
名前ボックスに A1:F12 を入力して選択。矢印 / Tab / Enterで移動。文字を打つと置換、F2で追記。Ctrl+Aで使用範囲、Ctrl+HomeでA1、Ctrl+Endで最終セル。行列の境界をドラッグしてサイズを変更、ダブルクリックで自動調整。
コピーと貼り付け
「Excelへコピー」またはCtrl+Cで選択範囲をコピーし、Excelで左上のセルを選んでCtrl+V。値（数値は全桁）、文字列（先頭ゼロ・空白・改行を含む）、表示形式、フォント、色、塗りつぶし、罫線、配置、折り返し、インデント、結合、リンクがこの表と同じになります（デスクトップ版Excelで確認）。数式は、参照先がすべてコピー範囲の中にあるときに数式として入り、範囲の外を参照する数式は計算結果の値として入ります。00123 や 1/2 のように数値・日付に見える文字列は、値が変わらないよう表示形式「文字列」で入ります。Excelからこの表への貼り付けでは、Excelに表示されていた値と書式を取り込みます（数式は値になります）。
貼り付け後に確認する項目
列幅と行の高さは、Excel同士でコピーしたときと同じく、貼り付け先のままです（行の高さは自動で調整されます）。数値が「####」と表示されたら列幅を広げてください。ブラウザー版Excelでは取り込み方が異なる場合があるため、大事な表は貼り付け後に見比べてください。
数式
同じシートのA1参照・範囲、四則演算・比較・文字連結、SUM / AVERAGE / MIN / MAX / COUNT / COUNTA / IF / ROUND。未対応の式はエラーを表示します。全Excel関数の実装ではありません。
保存
Ctrl+Sまたは「AIに渡す」で状態テキストを出力します。ファイル自体への自動保存はありません。編集の書き出し後も、元HTMLと状態テキストを一緒に保管してください。
シート
タブで切り替え、ダブルクリックで名前変更、＋で追加。緑の選択枠の右下をドラッグすると値・書式・相対数式をコピーします。数値2セルを選んで下へドラッグすると連続データになります。
