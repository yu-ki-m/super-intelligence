# Excelとの互換性

この資料は、このHTMLからコピーした表がExcelでどうなるかを、実機で測った結果と、その確かめ方をまとめたものである。
「HTMLとしてもっともらしい書き方」が、Excelでは別の意味に解釈されることがある。
そのため、クリップボード用HTMLの書き方は、すべて実測に基づいて決めている。

## 目次

- 測った環境と方法
- 結果
- クリップボードHTMLの書き方（実測済みの規則）
- Excelからこの表への貼り付け
- ブラウザー版Excelで確かめる手順
- 実装していない機能

## 測った環境と方法

2026-11-14 に、次の環境で測った。

| 項目 | 内容 |
|---|---|
| OS | Windows 11 Pro |
| Excel | デスクトップ版 Excel 2021（16.0.20326.20318、日本語） |
| ブラウザー | Google Chrome 157.0.8103.78 |

照合には `scripts/verify_excel_paste.py` を使う。
照合はWindowsのクリップボードを使うので、実行中にほかのアプリがクリップボードに書き込むと結果が乱れる。
差が出たときは、もう一度実行して再現するか確かめる。
この照合は、表を作った人が意図した状態と、貼り付けた結果を比べるために、次の3つを用意する。

1. **Excelで直接作った表（正解）**：ブックJSONと同じ値・数式・書式・結合を、Excelの中で直接設定した状態である。
2. **このHTMLからの貼り付け**：HTMLが書き出すクリップボードの内容を、Chrome / Edge と同じ形（CF_HTML）でWindowsのクリップボードに置き、新しいブックに貼り付けた状態である。
3. **参考：Excel自身のコピー**：1の範囲をExcel自身にコピーさせ、そのHTMLだけを貼り付けた状態である。

1と2を、セルごとに24項目で比べる。
項目は、値、表示文字列、数式の有無、数式、先頭の `'`、表示形式、フォント、サイズ、太字、斜体、下線、取り消し線、文字色、塗りつぶし、横位置、縦位置、折り返し、インデント、結合、リンク、上下左右の罫線である。
数値の表示文字列は、列幅が狭いと `####` になるので比べない（値と表示形式で比べる）。

加えて、実際のChromeで生成HTMLを開き、Ctrl+C と、Clipboard API で書き込むコピー処理の両方でコピーした。
後者は、いまはリボンと右クリックメニューの「コピー」が使う処理である（測定時は、のちに廃止した見出しの「Excelへコピー」ボタンから呼んだ）。
Chromeがクリップボードに書いたバイト列をそのままExcelに貼り、同じ照合をした。

## 結果

| 題材 | 想定外の差 | 仕様どおりの差 | 参考：Excel自身のコピーの差 |
|---|---|---|---|
| 全機能を集めた検証用ブック（108セル） | 0 | 13 | 36 |
| 同上を実際のChromeでCtrl+C | 0 | 13 | — |
| 同上を実際のChromeで「コピー」の処理（Clipboard API） | 0 | 13 | — |
| 見本 `assets/example.json`「業務一覧」 | 0 | 0 | 12 |
| 見本 `assets/example.json`「書式テスト」 | 0 | 0 | 4 |

**仕様どおりの差**は、次の2種類である。

- 数値・日付・真偽値・数式に変わりうる文字列（`00456`、19桁の数字、`TRUE`、`1/2`、`50%`、`=で始まる文字`、`'で始まる文字`）は、表示形式「文字列」（`@`）で渡す。
  Excelで直接作った表では、これらは「標準」に先頭の `'` が付いた状態になる。
  値と見た目は同じで、表示形式だけが異なる。
  `x:str` だけでもデスクトップ版では値が守られるが、`x:str` を読まない取り込み先（ブラウザー版の可能性がある）でも値が変わらないよう、`@` も付ける。
- コピー範囲の外を参照する数式は、計算結果の値として渡す（下の `x:fmla` の項を参照）。

**Excel自身のコピーが落とすもの**も分かった。
Excelがクリップボードに置くHTMLには、表示値と書式しかない。
そのため、HTMLだけを貼ると次の情報が失われる。

- 精度：0.123456 → 0.1235、3.14159 → 3.14
- 文字列の型：`00456` → 456、19桁 → 1.23E+18、`TRUE` → 真偽値、`1/2` → 日付
- 数式：値になる

このHTMLは `x:num` / `x:str` / `x:fmla` を書くので、これらを落とさない。

**列幅と行の高さ**は、どの方法でも貼り付け先のままである。
これは、Excelで作った表をExcel自身がコピーして Ctrl+V した場合も同じで、行の高さは中身に合わせて自動調整される。
Excelには「元の列幅を保持」という貼り付けのオプションがあるが、これはExcel独自の形式からの貼り付けにしか使えず、ブラウザーが書けるHTMLからは使えない。

## クリップボードHTMLの書き方（実測済みの規則）

`assets/core.js` の `clipboard()` と `xlCss()` は、次の規則で書き出す。
規則を変えるときは、`verify_excel_paste.py` で差が出ないことを確かめる。

| 書き方 | Excelでの意味（実測） |
|---|---|
| `<html xmlns:x="urn:schemas-microsoft-com:office:excel">` | これがないと、`x:` で始まる属性がすべて無視される |
| `x:str="値"` | その文字列がそのまま入る（先頭ゼロ、前後と連続の空白、改行 `&#10;` を保つ） |
| `x:str=""` | **文字列が空になる**（以前の版で、日本語の文字列がすべて消えた原因） |
| `x:str` の先頭の `'` | 接頭辞として消費される。文字としての `'` を残すときは `''` と重ねる |
| `x:num="1234567.891"` | 全桁の数値が入る。セルの中身（表示値）は使われない |
| `x:fmla="=A1*$B$1"` | 数式が入る。参照は貼り付けた範囲の左上をA1として読まれ、`$` 付きの参照も貼り付け位置に合わせてずれる。そこでコピー範囲の左上を基準に参照を書き直し、範囲の外を参照する数式は書かない |
| `white-space` を書かない | **折り返す** になる。折り返さないセルは `nowrap`、折り返すセルは `normal` を明示する |
| `<br style="mso-data-placement:same-cell">` | セル内の改行。素の `<br>` では、2行目以降が消えるか次の行に送られる |
| `font-family:"Yu Gothic";mso-font-charset:128` | フォント名は二重引用符で書く。`'Yu Gothic', sans-serif` のように総称名を続けると、Arial などに置き換わることがある |
| 罫線 `.5pt hairline` / `.5pt solid` / `1.0pt solid` / `1.5pt solid` | 極細 / 細線 / 中太線 / 太線。CSSの `1px` を書くと中太線になる |
| 罫線 `2.0pt double`、`.5pt dashed`、`1.0pt dashed`、`.5pt dotted` | 二重線、破線（細）、破線（中）、点線 |
| `background:#RRGGBB;mso-pattern:black none` | 塗りつぶし。塗らないセルには書かない（白で塗ると枠線が隠れる） |
| `text-align:general` | 横位置「標準」。`left` を書くと「左詰め」に固定される |
| `vertical-align` を書かない | 日本語版では上下中央。明示して書く |
| `mso-char-indent-count:2` | インデント2。`text-align` は `left` か `right` にする |
| `mso-number-format` | `General`、`"\@"`、`0`、`Fixed`、`"\#\,\#\#0"`、`Standard`、`0%`、`Percent`、`"\0022¥\0022\#\,\#\#0"`、`"yyyy\/mm\/dd"`。Excel自身が書く綴りをそのまま使う |
| `<a href="https://…">` | リンクになり、Excelのリンクの書式（青・下線）が付く |
| `colspan` / `rowspan` | 結合になる。罫線は結合範囲の外周に付く |
| `<span style="mso-spacerun:yes">` | ブラウザーが外側を `<html><body>` で包んだ状態では効かない。空白は `x:str` で守る |

ChromeとEdgeは、`text/html` を書くときに、渡したHTMLを `<html><body><!--StartFragment-->…<!--EndFragment--></body></html>` で包む。
Ctrl+C（`copy` イベント）と非同期API（`navigator.clipboard.write`）のどちらでも、中身の `x:` 属性や `mso-` の指定は書き換えられなかった。

## Excelからこの表への貼り付け

Excelがクリップボードに置くHTMLは、書式を `<style>` 内のクラス（`.xl65` など）で指定する。
取り込み処理（`app.js` の `importHTML` と `core.js` の `styleFromDecls` ほか）は、クラスとインラインの両方を、Excelの方言（pt単位の罫線、`Standard` などの書式名、`\0022` などのエスケープ）として読む。
上の検証用ブックをExcelでコピーし、このHTMLに Ctrl+V した結果を元の定義と比べた。
フォント・色・塗り・配置・折り返し・インデント・表示形式・結合・罫線は取り込めた。
残る差は、Excelのクリップボードが運ばない情報によるものである。

- 値は表示されていた桁になる（0.123456 → 0.1235）。数式は値になる。文字列の `TRUE` は真偽値になる。
- 罫線は、隣り合うセルの境界を片方のセルの辺として受け取ることがある（A2の下線がA3の上線になる）。見た目は同じである。
- 縦に結合したセルの下辺の罫線は、Excel自身のHTMLに書き出されない。
- 文字を伴わずに書式だけを持つ空のセルには、Excelが全角空白を入れるので、Excelと同じく空として扱う。

## ブラウザー版Excelで確かめる手順

ブラウザー版Excelは、貼り付けをブラウザー上のプログラムで処理する。
そのため、デスクトップ版と同じ結果になるとは限らず、まだ実機で確かめていない。
ブラウザー版で使う表は、次の手順で確かめる。
ログインはユーザーが行い、既存のブックには貼り付けない。

1. `assets/example.json`、または検証したい表をビルドし、Chrome か Edge で開く。
2. ブラウザー版Excelで新しい空白のブックを作る。
3. HTMLで範囲（例: `A1:H14`）を選び、Ctrl+C を押す。
4. Excelで A1 を選び、Ctrl+V を押す。
5. 次の項目を見比べ、異なるものをセル番地つきで記録する。
   - 先頭ゼロ（`00123`）と長い番号
   - 金額・百分率・日付の表示
   - 合計セルが数式になっているか（セルを選んで数式バーを見る）
   - 太字・色・塗り・罫線の種類
   - 結合
   - 折り返しとセル内改行
   - 列幅と行の高さ

差があれば、該当する書き方を上の表と照らし、`assets/core.js` を直してデスクトップ版の照合も通るか確かめる。

## 実装していない機能

次の機能は未実装、または Excel と動作が異なる。
依頼にこれらが必要なら、テンプレートを拡張して検証するまで「対応済み」として扱わない。

- セルの一部分だけの書式、縦書き・回転、条件付き書式、図形、画像、グラフ、フィルター、ピボット、入力規則、保護、コメント、印刷設定
- 非連続範囲の選択、行・列の非表示
- シートをまたぐ式、名前定義、上記以外の関数、動的配列
- 一覧にない表示形式（`#,##0_ ;[赤]-#,##0` など）。Excelから貼り付けると「標準」になる
- 狭い列での `####` 表示、ブラウザーとExcelのフォント描画の完全な一致
- 行・列の削除で範囲参照が縮むExcelの動作（このHTMLでは端点が消えると `#REF!` になる）
- 大きな表の仮想スクロール（上限は1シート500行・100列で、全セルを描画する）
