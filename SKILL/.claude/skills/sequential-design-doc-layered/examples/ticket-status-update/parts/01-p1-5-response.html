ErrorResponse は code・message の 2 項目（ErrorResponse.java:3）。入力検証の違反では message に項目名、ticketId の型の誤りでは message にパラメーター名が入る。 「Spring Boot の既定の形式」は、ハンドラーが無い例外を Spring Boot の /error が返す形：timestamp（発生時刻）・status（ステータスの数値）・error（理由句）・path（リクエストのパス）。message は既定の設定では含まれない（server.error.include-message の既定値）〔推定〕。
