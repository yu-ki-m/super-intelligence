毎週金曜に、自分の作業ログ（Markdown、1日1ファイル）から上司向けの週報を作っているので、これをスキルにしたい。週報には、今週やったこと、来週やること、困っていること（相談したいこと）を入れたい。ログが無い日や、書きかけのログもある。サンプルとして今週のログを置いておく（水曜は書き忘れた）。質問はしなくていいので自動で進めて。深さは軽量、反復は1回、テストの実行は合わせて8回まで。できたスキルは写しで渡して、どこにもインストールしなくていい。
