# 会議メモを整える

1. 指定されたフォルダの .md ファイルをすべて読む。
2. 各ファイルについて、次を行う。
   - 2行以上続く空行を1行にする。
   - 見出しを ## から始まるようにそろえる。
   - 「TODO」「済」「メモ」で始まる行を消す。
3. 同じファイルに上書きして保存する。
4. 「整えました」と伝える。
