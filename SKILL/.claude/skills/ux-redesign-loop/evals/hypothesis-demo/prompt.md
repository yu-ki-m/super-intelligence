病棟の看護師が、夜勤から日勤へ交代するときの申し送り（引継ぎ）の画面を作り直したいです。今は電子カルテの経過記録を1人ずつ開いて読み上げていて、30分以上かかります。軽めでいいので設計して、プロトタイプができたら、チームで仮説を話し合うためのデモも作ってください。画面の横で、看護師たちが何を言っていて、何を思っていて、どんな状況なのかが分かるようにしたいです。
