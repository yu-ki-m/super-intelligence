# shop-app（社内通販バックエンド）

- 言語：Python 3.12、DB：PostgreSQL 1台
- 開発者：4人（注文担当2人、請求担当1人、インフラ兼任1人）
- リリース：毎週木曜にまとめてデプロイする（全機能を1つのプロセスで配置）

## 最近の困りごと（開発チームのメモ）

- 消費税の端数処理や請求書の様式が変わるたびに、注文側のコード（src/orders/）まで直す必要がある。
- 請求担当が修正しても、注文担当のレビュー待ちで木曜のリリースに間に合わないことがある。
- 月末の請求締め処理が重い日に、注文画面の応答が遅くなるという問い合わせが2件あった（計測はしていない）。
- 「注文と請求を別サービスに切り出せば、請求側だけで自由にリリースできるのでは」という意見が出ている。
