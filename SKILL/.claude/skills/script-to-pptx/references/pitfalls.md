# よく起きる問題と直し方

実際に台本からスライドを作ったときに起きたことと、その直し方。
組み立てる前に一度読み、画像で確かめるときにも見返す。

## 見た目の問題（画像で見つかる）

| 起きること | 原因 | 直し方 |
| --- | --- | --- |
| 日本語が語の途中で改行する（「確か／める」「ツー／ル」「取／り」） | 箱の幅が足りず、PowerPoint が字の切れ目で折り返す | 文を短くする。2行にするなら、区切りたい所に `\n` を入れる。箱を広げる |
| 1文字だけが次の行に落ちる（「…ある／か」） | 文がわずかに幅を超えている | 言い回しを変えて数字分短くするか、意図した所で2行に分ける |
| 矢羽根の中の文字が細かく折れる | 矢羽根の文字の領域は、形の幅よりかなり狭い | 文字を4〜5字に短くし `\n` で2行にする。`margin: 0` と `pt: 13`。それでも収まらなければ `FLOW`（箱と矢印）に変える |
| 選択肢のラベル同士がくっつく | 行の間隔 `rh` が 0.36 前後 | `rh` を 0.42 以上にする。足りなければ上の図を詰める |
| 文字が箱からはみ出す、画面の右端で切れる | 幅を見積もりより長い文、右端の座標の計算違い | 右端が 12.733 を超えていないか計算し直す。幅は「全角1字 ≒ 文字の大きさ（pt）÷ 72 インチ」で見積もる |
| 図の下の注記と、下の要素が重なる | 2行になった注記の高さを見込んでいない | 注記の高さを2行分（0.7 前後）にとり、下の要素を下げる |
| 暗い背景の上の文字が見えない | 色を指定しなかった部分が既定の黒になる | 暗い背景では、すべての文字に `C.background1` か `C.accent6` を指定する。`STAT` の単位も同じ |
| 英字の下線（`tool_use` の `_`）が消えて「tool use」に見える | BIZ UD の下線は低く細く、小さい文字では表示されない | 英字は Segoe UI（本文）と Consolas（コード）で表示する。lib.js はそうしてある。英字のフォントを BIZ UD に戻さない |
| 大きな数字の 0 に斜線や点が入る | 等幅の Consolas の 0 は斜線入り | 大きな数字は本文のフォントで書く（`STAT` はそうしてある）。`fontFace: CODE` を付けない |
| 表のセルが空になる | 一部だけ書式を変えるセルに runs の配列をそのまま置いた | `{ text: [runs] }` の形にする。`inspect.js` は空のセルを知らせる |
| PowerPoint が「ファイルを開けません」と言う | 書式付きの文字（runs）に空の文字列 `""` が混ざった。pptxgenjs も `inspect.js` も警告しない | 文字は `T`（と、それを使う部品）で置く。`T` は空の文字列を取り除く。`s.addText` を直接使うときは、空の文字列を入れない |
| コードの行が箱の中で折り返す | 1行が箱の幅を超えている | 値の所で改行して複数行に分ける。文字を小さく（12pt まで）する |
| 長い矢印のラベルが、途中の線や別の部品に重なる | ラベルを矢印の中央に置いた | 近い2本の線の間にラベルを置く。部品は矢印の行と重ならない段にずらす |
| 箱と箱をつなぐ矢印が、箱の中から始まる | 箱の幅を変えたのに、矢印の座標を直していない | `FLOW` を使うか、矢印の始点を「箱の左端＋幅＋0.05」で計算する |

## 中身の問題

| 起きること | 防ぎ方 |
| --- | --- |
| 後で答える問いの答えが、スライドに先に出ている | 台本の「問いと答え」で答える段階を確かめる。答えはノートだけに置く。数字の問いなら「？」と書く |
| 説明のために作った例が、事実のように見える | 出典の行に「〇〇は説明のための例」「仮の数字」と書く |
| 判定や名前が原典と食い違う | 台本が挙げる資料を読み、原典の表記と判定に合わせる。食い違いは報告で伝える |
| スライドとノートの台詞が1枚ずれる | `def` の最初の引数を台本の指示と一字も変えずに書く。`build` が数と順番を確かめる |
| 台本の指示が見せると言っているものが、スライドにない | 指示の文を読み直し、指示にある言葉や数字がスライドにあるかを確かめる |
| 本文が台詞の書き写しになる | スライドは見せるもの、台詞はノート。文章は図の説明として一、二行にする |

## 環境の問題

| 起きること | 原因と直し方 |
| --- | --- |
| `render.ps1` が「ファイルが見つからない」で失敗する | 古い `render.ps1` は書き出し先の相対パスを扱えなかった。今のものは絶対パスに直す。古い写しが作業フォルダーに残っていたら、`setup.ps1` を流し直す |
| `render.ps1` が失敗する、止まる | PowerPoint が別の処理中か、ダイアログを出している。PowerPoint の画面を確かめてもらう。別の資料の作成を同時に流さない（PowerPoint は一つの資料ずつ確かめる） |
| PowerPoint がない | 組み立てはできる。画像での確かめができないことを報告で伝える |
| 一時フォルダーの中身が消える | 一時フォルダーは片付けられることがある。`setup.ps1` を流し直すと部品と pptxgenjs が戻る。`deck.js` は消える前に必要なら台本の横に写す |
| `require('pptxgenjs')` が見つからない | 作業フォルダーの中で `node deck.js` を実行しているか確かめる。`setup.ps1` を流し直す |
