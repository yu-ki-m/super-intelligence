# 朝会を15分から5分にした話

## 発表の条件

| 項目 | 内容 |
| --- | --- |
| 発表の型 | 知見の共有（LT） |
| 聞き手 | 社内の開発者 |
| 持ち時間 | 5分 |

## 台本

### 掴み

〔スライド：「朝会、毎日15分」〕
私のチームの朝会は、毎日15分でした。
ここで問題です。
5人のチームで、一か月に何時間になるでしょうか。
〔考える時間：約5秒〕
答えは、約25時間です。

### 変えたこと

〔スライド：変える前と後の比較〕
変える前は、全員が順番に、昨日やったことを話していました。
変えた後は、困っていることがある人だけが話します。

〔スライド：朝会の流れ。書く、読む、困りごとだけ話す〕
流れは三つです。
前の日の夕方に、やったことを書く。
朝会の前に、読んでおく。
朝会では、困りごとだけを話す。

### 結果

〔スライド：時間と満足度の表〕
一か月試した結果です。
時間は15分から5分になりました。

### 持ち帰り

〔スライド：「明日の朝会で、困りごとだけ聞いてみる」〕
明日の朝会で、一度だけ、困りごとだけを聞いてみてください。
