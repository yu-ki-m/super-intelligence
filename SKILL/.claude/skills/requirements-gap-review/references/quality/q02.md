# Q02 性能効率性(Performance Efficiency)

このカタログを、案件固有の要求候補を発見するために使う。各項目の適用条件・必要性・代替手段を確認し、一律に必須要件としない。技術例や数値をそのまま採用せず、案件の根拠に基づいて判断する。規格・法令・期限を判断に用いる場合は適用範囲と最新性を確認する。

項目IDを使って案件の根拠・要求候補・指摘・検証条件を結び付ける。

## Q02.01 時間効率性(Time Behaviour)

### Q02.01.001 応答時間(平均だけでなく p95/p99 パーセンタイル)

- `Q02.01.001.01` 画面・API ごとの目標値(SLO)の設定と計測
- `Q02.01.001.02` 平均に隠れる遅いリクエスト(テールレイテンシ)の監視
- `Q02.01.001.03` 目標超過時のアラートと改善着手の基準の定義
- `Q02.01.001.04` 用途別(対話操作/API/帳票出力)の目標値の使い分け

### Q02.01.002 応答時間のばらつき(ジッター)の小ささ

- `Q02.01.002.01` 同一操作の応答時間分布の計測
- `Q02.01.002.02` ばらつき要因(GC、バッチ同時実行、キャッシュミス)の特定
- `Q02.01.002.03` 「たまに遅い」という報告を再現・調査できる手段の確保

### Q02.01.003 スループット(単位時間あたり処理件数)

- `Q02.01.003.01` ピーク時間帯に必要な処理量の見積もり
- `Q02.01.003.02` 負荷試験による実測スループットの確認
- `Q02.01.003.03` スループットと応答時間のトレードオフの把握

### Q02.01.004 レイテンシ(遅延)

- `Q02.01.004.01` ネットワーク・DB・外部 API 等の遅延内訳の計測(トレーシング)
- `Q02.01.004.02` 拠点・地域による遅延差の把握
- `Q02.01.004.03` 遅延に敏感な対話的操作の特定と優先改善

### Q02.01.005 初回表示・体感速度(Web なら LCP・TTI 等)

- `Q02.01.005.01` Core Web Vitals(LCP、INP、CLS)の計測と目標設定
- `Q02.01.005.02` スケルトン表示・段階的レンダリングによる体感改善
- `Q02.01.005.03` 実ユーザー計測(RUM)と合成計測の併用

### Q02.01.006 起動・終了時間

- `Q02.01.006.01` アプリ・サービスの起動所要時間の計測
- `Q02.01.006.02` 起動時初期化処理の遅延実行化(必要になるまで待つ)
- `Q02.01.006.03` デプロイ・再起動直後のウォームアップの要否

### Q02.01.007 コールドスタート時間(サーバーレス・JIT 環境)

- `Q02.01.007.01` コールドスタートの発生頻度と所要時間の計測
- `Q02.01.007.02` 事前確保(プロビジョンドコンカレンシー等)・ウォームアップの検討
- `Q02.01.007.03` 初回リクエストが遅いことによるユーザー影響の評価

### Q02.01.008 バッチ処理の所要時間と処理時間帯への収まり

- `Q02.01.008.01` バッチウィンドウ(許容時間帯)の定義と実績の監視
- `Q02.01.008.02` データ増加時の所要時間の伸びの予測
- `Q02.01.008.03` 遅延時の後続ジョブ・オンライン開始時刻への影響の定義

### Q02.01.009 非同期処理・画面描画の待ち時間

- `Q02.01.009.01` 非同期化すべき重い処理の特定基準(数秒超等)の設定

### Q02.01.010 タイムアウト設定の妥当性

### Q02.01.011 ロック競合・DB コネクション取得待ちによる遅延

- `Q02.01.011.01` ロック待ち時間・プール枯渇の監視

### Q02.01.012 非効率なデータアクセスの有無(N+1 クエリ、全件走査)

### Q02.01.013 インデックス設計・実行計画の妥当性

- `Q02.01.016.01` WebP/AVIF 等の採用と画面サイズ別の出し分け(srcset)

### Q02.01.018 ファイルアップロード/ダウンロードの速度

### Q02.01.020 帳票・大量エクスポートの生成時間と非同期化

### Q02.01.021 低速回線・高遅延環境での応答性

- `Q02.01.021.01` 低速回線相当での動作確認(回線スロットリング試験)
