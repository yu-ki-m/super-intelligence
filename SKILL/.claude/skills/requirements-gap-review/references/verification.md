# 検証と評価

分析対象の性質に合わせて使う。すべての変更に形式モデルや網羅テストを要求しない。

## 観点の収録と分析台帳を検査する

[台帳手順](coverage-workflow.md) の `check-catalog` で同梱カタログの整合を、`validate` で案件の台帳のID・状態・根拠欄を確認する。カタログが壊れていないこと、分析の記録が埋まっていること、必要条件を正しく発見できたことは別の検証である。[実行プロセス](process.md) のP4でL1〜L3、G01〜G10の内容を確認し、台帳チェックだけで検証工程を完了しない。

スクリプトの評価には、1項目の欠落、ID重複、カタログ版違い、根拠なしの充足・対象外、未確認に次行動がないケースを含める。全部未分析の台帳が合格判定に見えないこと、指摘が残ったまま処理済みとなり得ることも確認する。

## 有限の条件・状態を検査する

1. 対象の不変条件、状態、入力、操作、外部環境の仮定を定義する。
2. 条件の値域と制約を列挙し、意味のある組合せを作る。除外には根拠を付ける。
3. 各ケースに期待結果と出典・未決定の判断を付ける。未決定セルを都合のよい期待結果で埋めない。
4. 組合せの欠落、矛盾した期待結果、到達不能という仮定の妥当性を確認する。
5. 不変条件に反する具体的な入力・操作順序を探し、実装・設計と照合する。

認可なら主体×対象×操作×状態、再処理なら成功・失敗×応答消失×再送回数×並行数などが候補。全組合せを調べられない場合はリスクで選び、未検証領域を示す。ペアワイズを使っても3条件以上の相互作用を保証しない。

状態表には現在状態、イベント、ガード、次状態、副作用、失敗・取消時の状態を置く。正常遷移に加え、禁止操作、途中失敗、再開、権限やデータの変化を確認する。

## 非機能条件を検証可能にする

性能・容量・復旧時間などは測定対象、負荷、データ量、環境、測定開始・終了、統計値、合格閾値が必要。根拠がない閾値を捏造せず、測定方法の案と決定すべき値を分ける。

運用要件は「ログが出る」だけで完了とせず、検知、原因特定、担当への到達、対処、整合性回復までの対象範囲を定める。機密情報を記録しすぎない条件も、適用する情報管理要件と照合する。

## モデル検査を使う場合

並行性、状態遷移、制約の衝突が複雑で、通常の表や具体例では判断が難しい場合に検討する。利用可能なTLA+、Alloy等の手段は環境と依頼範囲に合わせる。

- 守る性質と環境の仮定を別に記述する。状態数、主体数、データ数、時間・試行回数等の境界を明示する。
- 非同期処理の完了を論じるときは、外部サービスの回復やスケジューリング等の前提を明示する。
- 反例があれば操作列と対応する実装経路を出す。モデル内の現象だけなら実装で未確認とする。
- 反例なしは探索したモデル・境界での結果とし、仕様自体の完全性や全実行の安全を証明したことにしない。
- ツールが利用できない場合は決定表・具体的な操作列で代替し、モデル検査済みとは書かない。

## スキルの検出能力を評価する場合

過去の漏れが発見される前のコード・設計・要求を入力にし、後の修正・障害報告を評価用正解として分離する。人工欠落は補助に使えるが、実際の未知要求の発見能力とは区別する。

欠落を含むケースだけでなく、共通層で満たされる条件、承認された廃止、小規模で影響が限定された変更、資料不足、実装のない設計案を含め、誤検出を確認する。

評価項目：

- 必要な不足を具体的な根拠と経路で発見できたか。
- 仕様の不足、実装不具合、未確定の期待を分離できたか。
- コード・設計・テストが一致していても業務が成立しない事例で、修正すべき仕様・要件・要求を遡って特定できたか。
- 未変更の影響先と失敗・境界条件を検討できたか。
- 現行動作を無条件に維持させず、共通層や承認済み変更を反証として扱えたか。
- 開発側で決められない事項を、選択肢と影響のある判断資料にできたか。
- 確認できない情報を捏造せず、分析範囲・限界を説明できたか。
- HTML指摘表の全行に根拠・確度（%と理由）・推奨する修正があり、修正案と検証条件が業務上の差を解消するか。

正解集合がある場合のみ、既知欠陥への再現率 `TP/(TP+FN)` と適用が確定した指摘の正確率 `TP/(TP+FP)` を使う。ゼロ分母は算出不能にする。未裁定の候補を一律に誤検出と数えず、未裁定数として別に報告する。重大度別の見逃し、反証の成功、エスカレーションの判断可能性も見る。自己点検は独立評価ではないと明記する。

分析結果が増えたことだけを改善の証拠にしない。実際の見逃しや誤検出に対応して観点や根拠の扱いを修正し、無関係な要求を一律に追加する規則にしない。
