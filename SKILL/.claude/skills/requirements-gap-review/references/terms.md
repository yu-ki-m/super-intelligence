# 品質特性・副特性の別表記

組織や資料によっては、次の8件を別の表記で呼ぶ。表にない特性・副特性は、カタログと同じ表記が一般的。報告では判断原則の「組織の用語を優先する」に従い、組織の表記にカタログIDを併記する。

| ID | カタログの名称 | 別表記 |
|---|---|---|
| Q04 | 相互作用性(Interaction Capability) | インタラクション容易性（対話性）（Interaction capability） |
| Q04.04 | ユーザーエラー防止性(User Error Protection) | ユーザエラー防止性 |
| Q04.07 | ユーザー支援性(User Assistance) | ユーザ支援性 |
| Q05.02 | 可用性(Availability) | 可用性（アベイラビリティ） |
| Q05.03 | 障害許容性(Fault Tolerance) | 障害許容性（耐故障性） |
| Q08.03 | 設置性(Installability) | インストール性（設置性） |
| Q09.02 | リスク特定性(Risk Identification) | リスク識別性 |
| Q09.03 | フェイルセーフ(Fail Safe) | フェールセーフ |
