
## 1. 全機能を有効化する基本設定

```
claude mcp add --scope user playwright -- npx -y @playwright/mcp@latest --caps=network,storage,testing,vision,pdf,devtools,config --console-level=debug --snapshot-boxes
```

| Capability | 有効になる機能                               |
| ---------- | ------------------------------------- |
| `network`  | HTTP通信のモック、通信状態の操作                    |
| `storage`  | Cookie、localStorage、sessionStorageの管理 |
| `testing`  | UI検証、アサーション、Locator生成                 |
| `vision`   | 座標によるクリック、ドラッグ、スクロール                  |
| `pdf`      | PDF出力                                 |
| `devtools` | Trace、動画撮影、操作記録、デバッグ                  |
| `config`   | MCPの有効設定を取得                           |
| `core`     | 画面操作、スクリーンショット、JavaScript実行など（標準で有効）  |

## 2. 制限も緩和した最大権限構成

```
claude mcp add --scope user playwright -- npx -y @playwright/mcp@latest --caps=network,storage,testing,vision,pdf,devtools,config --allow-unrestricted-file-access --grant-permissions=clipboard-read,clipboard-write,geolocation,notifications,camera,microphone --ignore-https-errors --console-level=debug --snapshot-boxes --timeout-action=30000 --timeout-navigation=120000
```

| オプション                              | 効果                                 |
| ---------------------------------- | ---------------------------------- |
| `--allow-unrestricted-file-access` | ワークスペース外のファイルと `file://` へのアクセスを許可 |
| `--grant-permissions`              | 指定したブラウザ権限を事前に付与                   |
| `--ignore-https-errors`            | HTTPS証明書エラーを無視                     |
| `--console-level=debug`            | 詳細なコンソールログを取得                      |
| `--snapshot-boxes`                 | 要素の座標・領域をスナップショットに追加               |
| `--timeout-action=30000`           | 操作タイムアウトを30秒に延長                    |
| `--timeout-navigation=120000`      | ページ遷移タイムアウトを120秒に延長                |

ただし、この設定ではブラウザからローカルファイルやカメラ・マイクなどにアクセス可能になる。    
実行するWebページを信頼できる場合に限定すること。  

## 3. Claude Code側でもMCPを自動承認する

プロジェクトの `.claude/settings.local.json` に以下を設定する。

```
{
  "permissions": {
    "allow": [
      "mcp__playwright__*"
    ]
  }
}
```
これにより、Playwright MCPの全ツールをClaude Code側で事前承認する。
ただし、`browser_run_code_unsafe` も自動承認の対象になる。  
このツールはMCPサーバー上で任意コードを実行できる。  

Claude Codeの他のツールも含め、すべての承認確認を省略する `--dangerously-skip-permissions` も存在するが、
これはPlaywrightだけでなくファイル編集やシェル実行などにも権限が及ぶ。

## 4. さらに利用できる便利なオプション


| オプション                     | 用途                                   |
| ------------------------- | ------------------------------------ |
| `--extension`             | 既存のChrome・Edgeに接続する                  |
| `--cdp-endpoint`          | CDP経由で既存ブラウザに接続する                    |
| `--proxy-server`          | mitmproxyなど外部プロキシと組み合わせる             |
| `--init-page`             | 起動時にPlaywrightコードを実行する               |
| `--init-script`           | 各ページでWebアプリのJavaScriptより前にスクリプトを実行する |
| `--save-session`          | MCPセッション情報を保存する                      |
| `--block-service-workers` | Service Workerを無効化して、通信横取りの制約を減らす    |
| `--headless`              | 画面を表示せずブラウザを実行する                     |
